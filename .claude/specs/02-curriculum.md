# 02: Curriculum content (L1 to L3)

Priority: P0 · Depends on: 01-foundation

## Goal
All teaching content as typed, validated data, so the engine can pick and grade activities with no LLM involved.

## Files
- `src/engine/curriculum/types.ts`: types and Zod schemas below.
- `src/engine/curriculum/l1.ts`, `l2.ts`, `l3.ts`: content.
- `src/engine/curriculum/index.ts`: `curriculum`, `getSkill(id)`, `getLevel(n)`, `skillsForLevel(n)`. Validates all content with Zod at module load in dev and in tests.
- `public/cards/`: one SVG or emoji-based picture per item (prefer inline emoji or simple SVGs; no stock photos).

## Types and schemas
```ts
type LevelId = 1 | 2 | 3
type Skill = {
  id: string              // 'l1.letters.a-e', 'l2.animals', 'l3.i-like'
  level: LevelId
  title: string           // shown to parents: 'Letters A to E'
  unit: string            // 'letters' | 'sounds' | 'colors' | 'numbers' | 'greetings' | 'animals' | ...
  order: number           // teaching order inside the level
  items: Item[]           // 4 to 10
  activityKinds: ActivityKind[]
}
type Item = { id: string; word: string; picture: string /* emoji or /cards/x.svg */; sound?: string /* phonics hint, 'buh' */; sentence?: string /* L3 */ }
type ActivityKind = 'listen-tap' | 'say-it' | 'picture-match' | 'odd-one-out' | 'first-sound' | 'finish-sentence' | 'build-story'
type Activity = {
  id: string; skillId: string; kind: ActivityKind
  prompt: string          // the scripted line Pip says, also the fallback: 'Tap the cat!'
  choices: Choice[]       // 2 to 4 picture cards; 2 for AGE_3_4 on first attempts
  answerId: string | null // null for open activities (say-it, build-story)
  hint: string            // 'Cat starts with c-c-c'
}
type Choice = { id: string; label: string; picture: string }
```

## Behavior
Content outline (each skill 4 to 10 items):
- **L1 Sounds and letters:** letters A-E, F-J, K-O, P-T, U-Z (sound + picture word), colors (red, blue, yellow, green, orange, purple), numbers 1-5, numbers 6-10, greetings (hello, goodbye, please, thank you), shapes (circle, square, triangle, star).
- **L2 Words:** animals, food, family, body parts, toys, weather, clothes, CVC words (cat, dog, sun, hat, pig, bus, bed, cup).
- **L3 Sentences:** "I like ___", "This is a ___", "I see a ___", "I feel ___" (feelings, ties to SEL), "Can I have ___, please?", yes/no questions ("Is the sun hot?"), tiny stories (3 picture steps to order).
- Activities are generated by `buildActivity(skill, kind, rng, ageBand)`: choose a target item, distractors from the same skill (never the same picture twice), shuffle with the seeded rng.
- Words are concrete, common and culturally neutral. No brands, violence, religion or scary items.

## Tests
- All content passes the schema; every skill has at least 4 items; ids are unique.
- `buildActivity` is deterministic for a fixed seed, always includes the answer, never duplicates choices, gives 2 choices for AGE_3_4 first attempts.

## Acceptance checklist
- [ ] At least 6 skills per level.
- [ ] Every item has a picture.
- [ ] Parent-facing titles read well in the dashboard.

## Out of scope
Audio files (Web Speech speaks everything).
